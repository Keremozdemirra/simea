# Working queue

Research, not software: items here are finished when an argument holds up, not
when tests pass. An item stays unchecked and picks up a `status:` note if it
spans more than one working session.

Standing rules:

- every citation verified against the original before it enters a manuscript
- every draft carries its own limitations section, written honestly
- claims stated so that they could come out false
- no number without a source and a vintage
