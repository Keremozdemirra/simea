# SIMEA — the framework

The original statement of the model: the agent as decision-subject, the three
constructs (Influence Gradient, Autonomy Threshold, Systemic Entropy), the core
decision function, and an autonomy-weighted welfare function.

- [simea-framework.pdf](simea-framework.pdf)

**Status:** draft, August 2025. Not yet submitted.

Known gaps, carried forward as open problems for the programme:

- the constructs are defined but not operationalised — *AT* in particular has no
  measurement instrument
- the welfare function is proposed rather than derived, and its axiomatic
  foundations are not worked out
- no empirical application yet
